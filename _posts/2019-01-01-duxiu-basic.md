网上流传的中文电子书，几乎都是从读秀网传到公网的。广大用户对电子书的需求，催生了一条完整的利益链条——有权限的人卖权限，有技术的人搬库（下载整个图书馆的电子资源），有渠道的人打包成软件、网盘出售，再有就是遍地开花的图书小贩，几块一本往外卖。

# 1

**1. 读秀**（[http://duxiu.com](http://duxiu.com)）是一家批量扫描、索引图书的公司，其宣传说有 10 亿页中文图书。

1.1  读秀将电子图书全文（包库）权限批量出售给单位、机构，单位指定的 IP 可以访问购买的电子图书全文。单位可自由买多买少，但没有一家单位买下了读秀所有的电子全文（全库）。

1.2  对于单位购买的图书，可以浏览全文。未购买的图书，可以预览一部分（试读）。有试读的图书（通常有封面），读秀可能有全文。已有 SS 号的书，一定有全文。

1.3  **SS 号**是 8 位编码，从 100- 到现在的 149-，表示入库时间，无意义。可由 SS 号反查封面、目录，但查不到标题等其它信息。DXID 是一串 12 位的数字，任何一本书均有。

1.3  读秀有许多马甲，包括超星、汇雅等，实质都是那些数据。常用查询试读的公开网站有深圳文献港、长春数字图书馆。

1.4 部分大学有**自建库**（馆藏数字化平台），扫描后会进入读秀主站，但是在读秀上查不到是哪家大学扫描的。自建库的电子图书，扉页允许有图书馆的章、标记等，主站的电子书，上面的图书馆章会被覆盖或遮挡。

# 2

**2.** 读秀的图书采用 **PDG** 后缀（整本图书是 PDZ 格式）储存，对应多种编码方式。

2.1  用户在网页浏览，看到的、下载到的都是低质量（150 dpi）的图片、PDF，部分有「好学近乎知」的篆书水印（此水印在 PDG 中不存在）。

2.2  对于包库图书，用户可在阅读器（**SSReader**）浏览、下载，得到的是高清的 PDG（300 dpi），但经过阅读器加密了。为了获得未加密的 PDG，就要在阅读器加密之前获得 PDG 文件，方法是用 HTTP Analyzer（获取 HTTP 请求，俗称「**报文**」，同类软件均可）与**棒棒糖**（CxCandy，模拟阅读器逐页下载）搭配使用，正常阅读的同时抓包，将报文填入棒棒糖后即可下载。

2.3  对于**无包库**全文的图书，可分段咨询（最普通的方法，时间长、图片模糊）获得全文，也可寻找有该书包库的单位，进入该单位读秀后用 2.2 的方法下载。对于**自建库**的图书，通常只有 **17 页**的阅读限制，转换链接后可阅读全文，再批量保存图片即可，自建库的图书放大到最大是有 300 dpi 的。

2.4  PDG 被称作「平底锅」，图书的 PDG 链接又被称作「锅链」，其链接有有效期，访问时不限制 IP。

# 3

**3.**  获得 PDG 后通常转至 PDF **保存**。

3.1  使用**老马**（strnghrs，博客 www.http://cnblogs.com/stronghorse）编写的软件 pdg2pic 将 \*.pdg 转至单页图片或全本 pdf。若是文字版 PDG（如 SS 9- 开头的非扫描书），可用该软件解密为 PDF。

3.2  若用阅读器下载得到的 PDG，黑白页面可用 CoffeeEnt（作者老鹰）解密，或 PIZZA（作者车明，我没用过）解密；彩色页面为 6aH 格式，无法解密。目前，解密方法已很少使用，通常直接下载未加密 PDG。

3.3  图片处理，推荐老马编写的 ComicEnhancer Pro（简称 CEP），可批量将图片处理为二值 TIFF（同时去毛边、去噪点），文件长度大幅减小。CEP 功能不限于此。若图片经过处理，通常保存原始 PDG。

3.4  对于**书签**，如果是包库图书，通常直接能下载到书签文件（BookContents.dat），对于其它有 SS 号的图书，可以反查书签。

# 补充

**1. 如何寻找有某书包库的单位？**　进入某书的详情页后，点击右侧「获取途径」中的「更多」会打开一个新的页面，在该页网址后加「\&type=1」即可看到有该书包库的单位。很多大学的图书馆在读秀中引入了第三方网站，如「万方」、「你选我买」等获取途径，这些也会被判定为有包库，但实际并没有电子全文。如果本页面为空，说明只有自建库才有全文，具体哪家无从得知。

**2. 书签、自建库？**　这是些见光死的技术，笔者也不会。


# QA

Q：如何尽可能多地合法获得读秀权限？

A：

1. 本专科学生，访问本校图书馆的数字资源，
2. 省、市级图书馆办卡，可访问该馆的数字资源，
3. 在支付宝申请浙江省图书馆的电子卡。

Q：上述途径都没有，我该怎么办？

A：
1. 买本实体书，切掉装订后扫描，
2. 在淘宝搜「电子书」，将 SS 号发给卖家，通常几块钱一本（3\~10￥），
3. 留意书贩的宣传，部分软件、网站提供查询下载，可能会稍便宜（1\~2￥），务必谨慎充值！
4. 在网上读书园地发帖求书。

Q：为什么要转成 PDF 保存，这一过程是否有损？

A：因为支持 PDF 的软件更多，各终端阅读也很方便，相比之下 PDG 就很小众了。用老马的软件（pdg2pic）转换可以做到无损，不转换的话也可用老马的 UnicornViewer 直接看。有人说从 pdg 提取出的图片质量比 pdg 本身还要高，这就是瞎扯了。
